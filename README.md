# Andara Beat 'Em Up

![Godot Engine](https://img.shields.io/badge/Godot-4.x-blue.svg)
![Status](https://img.shields.io/badge/Status-Prototype-orange.svg)

Selamat datang di repositori resmi **Andara Beat 'Em Up**! 

Game ini adalah sebuah *2D Platformer Beat 'Em Up* penuh aksi yang berlatar di jalanan fiksi bernuansa urban, **Kota Andara**. Proyek ini dikembangkan menggunakan **Godot Engine 4** oleh **Zennyx Interactive Studio**.

## 🎮 Tentang Game Ini
Terinspirasi dari game pertarungan klasik dan modern (seperti *Shank* dan *Guacamelee*), Andara Beat 'Em Up menawarkan pertarungan jarak dekat yang cepat, brutal, dan memuaskan. Saat ini game masih berada dalam tahap *Vertical Slice Prototype*.

### 🚀 Fitur Saat Ini (Milestone 1)
- **2D Platforming Physics:** Sistem gravitasi dan lompatan yang responsif.
- **Sistem Pertarungan (Combat):** Hitbox tinju dinamis dengan deteksi tabrakan presisi.
- **Game Feel (Juice):** Layar bergetar (*Camera Shake*) dan efek terpental (*Knockback*) saat pukulan mendarat.
- **Kecerdasan Buatan (Enemy AI):** Musuh yang memiliki "radar" untuk melacak dan mengejar pemain, serta memberikan pukulan jika jaraknya sudah dekat.
- **HUD & Sistem Nyawa:** Bar darah (HP) dinamis untuk pemain dan musuh, lengkap dengan kondisi *Game Over* (Auto-Restart).

## 🕹️ Cara Bermain (Kontrol Prototype)
- `A` / `D` atau `Panah Kiri` / `Panah Kanan` : Berjalan
- `Spasi` / `Enter` : Melompat
- `J` : Meninju (Serangan Dasar)
